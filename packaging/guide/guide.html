01关于这个项目About this project

用 AI 编程代理快速做一个 Rhino 插件Building a Rhino plugin quickly with an AI coding agent

Moyu 是一个研究和教学项目：看一个编程代理能多快、多可靠地做出一个完整的 Grasshopper 插件，包括数值求解器、自定义视口显示、键盘鼠标交互和测试。几乎所有代码、测试和文档都由 Claude Code 编写；作者提需求、看结果、在 Rhino 里试玩；图标由 OpenAI Codex 生成。Moyu is a research and teaching project: how quickly and how reliably can a coding agent build a complete Grasshopper plugin, with numerical solvers, custom viewport display, keyboard and mouse interaction, and tests? Almost all of the code, tests and documentation were written by Claude Code; the author asked for each part, reviewed it and play-tested it in Rhino; the icons were drawn with OpenAI Codex.

每个部分研究什么What each part studies

拓扑优化（数值）Topology optimisation (numerics) · 代理能不能写对带测试的工程数值代码：有限元、SIMP + 最优准则法、密度过滤、2D 带状 Cholesky、3D 多重网格共轭梯度；以及怎样用 Timer 让优化在 Grasshopper 里实时迭代、边算边改。Can an agent get engineering numerics right, with tests: finite elements, SIMP with optimality criteria, a density filter, a banded Cholesky solver in 2D and multigrid conjugate gradients in 3D; and how a Timer makes the optimisation iterate live in Grasshopper while you edit it.
四个小游戏（交互与视口）Four small games (interaction and the viewport) · 从一个 Grasshopper 组件出发，Rhino 视口能做到什么：用显示管线稳定地画整个场景和 HUD；安全接管键盘鼠标，并在对话框、Grasshopper 和 Rhino 命令需要时让出去；控制镜头；一帧之内把同一份数据换成另一种图（老板键）。How far the Rhino viewport goes from one Grasshopper component: drawing a whole scene and a HUD with a display conduit at a steady frame rate; taking the keyboard and mouse safely and handing them back to dialogs, Grasshopper and Rhino commands; driving the camera; redrawing the same data as a different drawing in one frame (the boss key).
VoxStack · 视角在转时的三维移动与旋转；可拖动的 gumball。moving and turning in 3D while the view turns; a draggable gumball.
Serpentine · 任意曲面变成场地（UV 网格、闭合、修剪、坡度）；第一人称镜头。any surface as a playing field (UV grid, wrap, trims, slope); a first-person camera.
Rebound · 平面上的实时碰撞和鼠标控制；参数化砌法当关卡。real-time collision and mouse control on a plane; parametric brick bonds as levels.
Swift · 单键节奏、程序生成关卡，用自动驾驶验证每关能过。one-key timing and generated levels, checked by an autopilot.

042D 拓扑优化2D topology optimisation

2D 像素拓扑优化2D pixel topology optimisation

在一个平面里画出设计域和条件，求解器一步步把材料挪到传力需要的地方（SIMP：体积受限下的最小柔度）。下面是典型连线。Draw a design domain and its conditions in a plane; the solver moves material, step by step, to where the load path needs it (SIMP: minimum compliance under a volume limit). The typical wiring:

@@WIRING2D@@
Boundary 2D闭合平面曲线 → 方形像素网格；套在里面的曲线是孔。自动识别 XY / XZ / YZ 平面。Closed planar curves → a square pixel grid; nested curves are holes. Works in the XY, XZ or YZ plane.
Load 2D点或曲线上的力（世界坐标向量），曲线上平均分到经过的节点。A force at points or along curves (a world vector), spread evenly along a curve.
Support 2D点或曲线约束，分别锁 X / Y：两向 = 铰支，单向 = 滚动支座。Fixes points or curves in X and/or Y: both = pinned, one = roller.
Area 2D始终实心（如楼板）或始终空心（如洞口）的区域。Regions that stay solid (a slab) or stay empty (an opening).
Material 2D杨氏模量 E、泊松比 ν（平面应力）。Young's modulus E and Poisson's ratio ν (plane stress).
SIMP Solver 2DRun 为真时每跳推进 Steps 步，Timer 一直推到收敛；Reset 从均匀密度重来。V 体积分数、P 惩罚、R 过滤半径。While Run is true each tick advances Steps iterations, and the Timer keeps it going until it converges; Reset starts over. V volume fraction, P penalty, R filter radius.
Visualize 2D三种显示（密度 / 实心 / 平滑）、阈值轮廓曲线（可以直接拿去建模）、荷载与支座符号。Three display modes (density, solid, smooth), a threshold outline curve you can model with, load and support symbols.

迭代过程How it converges

边算边改。运行中拖动荷载、支座或改参数，求解器保留当前密度继续收敛，不用从头再来；想重新开始按 Reset。Edit while it runs. Drag a load or a support, or change a parameter, and the solver carries on from the current density; press Reset to start from scratch.

053D 拓扑优化3D topology optimisation

3D 体素拓扑优化3D voxel topology optimisation

连线和 2D 一样，组件名把 2D 换成 3D：设计域是封闭实体，条件可以加在点、曲线或面上，求解器用多重网格预条件共轭梯度。The same wiring with the 3D components: the domain is a closed solid, conditions sit on points, curves or faces, and the solver uses multigrid-preconditioned conjugate gradients.

Boundary 3D封闭 Brep / 网格 → 立方体素。Resolution = 长边体素数（默认 32，最高 160）；套在里面的实体是孔。A closed Brep or mesh → cubic voxels. Resolution = voxels along the long side (default 32, at most 160); solids inside are holes.
Load 3D点、线、面上的力，默认 (0, 0, −1)，总力平均分到接触的节点。A force on points, curves or faces, default (0, 0, −1), shared by the nodes it touches.
Support 3D点、线、面上的约束，分别锁 X / Y / Z。Fixes points, curves or faces in X, Y and/or Z.
Area 3D封闭实体围出的始终实心 / 始终空心区域。Closed solids that stay solid or stay empty.
Material 3DE、ν（三维各向同性）。E and ν (isotropic 3D).
SIMP Solver 3D默认体积分数 0.2、过滤半径 1.5、每跳 2 步。Defaults: volume fraction 0.2, filter radius 1.5, 2 steps per tick.
Visualize 3DMode 0 体素块 / Mode 1 光滑等值面；另输出闭合网格和逐体素密度。Mode 0 voxel blocks, Mode 1 smooth isosurface; also outputs a closed mesh and per-voxel densities.

选 Resolution：体素数随它的三次方增长Choosing Resolution: the voxel count grows with its cube

@@VOXCHART@@
2D 和 3D 通用的上限Limits shared by 2D and 3D
  • Steps 最多 50；每跳算满约 1.5 秒就停在当前步，剩下的留给下一跳，Rhino 不会卡住。按 Esc 停得更早。Steps is at most 50; each tick stops after about 1.5 s and leaves the rest to the next one, so Rhino stays responsive. Esc stops it sooner.
  • 过滤半径：2D 1–12，3D 1–6。收到 NaN 或无穷大时按默认值算并警告。Filter radius: 1–12 in 2D, 1–6 in 3D. NaN or infinity falls back to the default, with a warning.
  • 状态：Waiting 缺输入；Unstable 结构是机构（加支座）；Error 原因在消息里。Status: Waiting = an input is missing; Unstable = a mechanism (add supports); Error = see the message.

06游戏的共同操作Playing the games

四个游戏，一套操作Four games, one set of controls

游戏画在当前的 Rhino 视口里，Grasshopper 画布只用来开始和设置。每个游戏开局都很慢、很简单，逐渐变难；默认静音。The games draw in the active Rhino viewport; the Grasshopper canvas only starts and sets them up. Every game starts slow and easy and ramps up; all of them are silent.

开始和结束Start and stop
点游戏组件下方的 ▶ Run 开始，再点 ■ Stop 结束。点 Run 会把焦点交给 Rhino 主窗口，一开局按键就有效。组件被禁用时 Run 不起作用。Press ▶ Run under a game component to start and ■ Stop to end. Run hands the focus to the Rhino window, so the keys work at once. A disabled component ignores Run.
组件输出（分数、体块、路线、指标……）只在暂停、老板模式和结束时刷新，游戏进行中 Grasshopper 不会重算。The outputs (score, mass, route, metrics…) refresh only when you pause, switch to the boss screen or finish, so Grasshopper does not recompute while you play.

08Landscape · Serpentine

Serpentine蜿蜒 · 曲面上的贪吃蛇a snake on any surface

蛇沿曲面的 UV 网格一格一格走。曲面在某个方向闭合（圆管、环面、球）就能绕过去，开放的边是墙，修剪的洞是障碍；下坡快、上坡慢，曲面的形状就是关卡。The snake moves cell by cell along the surface's UV grid. Closed directions (tube, torus, sphere) wrap around, open edges are walls and trimmed holes are obstacles; downhill is faster, uphill slower, so the surface is the level.

11常见问题与卸载Troubleshooting and uninstall

常见问题Troubleshooting

游戏里按键没反应The game ignores my keys焦点不在 Rhino 主窗口。点一下游戏视口，再按 Esc 继续。The Rhino window does not have the focus. Click the game viewport, then press Esc.
游戏突然暂停了The game paused by itself对话框、Grasshopper 窗口或 Rhino 命令拿走了键盘。处理完点回视口、按 Esc。A dialog, the Grasshopper window or a Rhino command took the keyboard. Finish there, click the viewport, press Esc.
点 ▶ Run 没反应▶ Run does nothing组件被禁用（锁定）了，或者组件上有报错气泡，原因写在气泡里。The component is disabled (locked), or it shows a warning balloon that says why.
求解器显示 WaitingThe solver says Waiting缺输入，通常是荷载或支座没接上。An input is missing, usually the loads or the supports.
求解器显示 UnstableThe solver says Unstable结构是机构，能自由移动或转动。加支座，或者让支座锁住两个方向。The structure is a mechanism that can move or spin. Add supports, or fix them in both directions.
3D 每步很慢3D steps are slow体素太多。降低 Resolution 或过滤半径；超过 15 万体素每步要几秒，超过 100 万会警告（第 6 页）。Too many voxels. Lower Resolution or the filter radius; above 150k voxels a step takes seconds, above 1M you get a warning (page 6).
"Moyu data cannot be internalised""Moyu data cannot be internalised"右键 Internalise 存下来的 Moyu 数据无法还原。把产生它的组件重新接上。Moyu values stored with right-click › Internalise cannot be restored. Reconnect the component that made them.
"No Timer drives this solver""No Timer drives this solver"文档里没有 Timer。接一个 Params › Util › Trigger 到求解器上，或者手动反复触发。There is no Timer in the document. Wire Params › Util › Trigger to the solver, or recompute by hand.

## 怎么归类

`dev-time-stats.md` 里每一行（一个时间段）按主要内容**整段**归到一类，不再细拆：

- **方案与原型**：读代码、构思玩法、在 Rhino 里做原型截图、写方案网页；拆需求。
- **写代码与自动测试**：核心规则、Rhino 端绘制和组件、单元测试、无界面 Rhino 测试、测试 GH 文件生成器。拓扑优化的两段大块（2D 测试工程、3D 多重网格）里也含少量文档，按主要内容算在这里。
- **Rhino 实机测试与修复**：在真 Rhino 里试玩、真实按键 / 鼠标测试，以及测出来的问题的诊断和修复（按键去重、gumball 拖动、4K 实测等）。
- **画面设计与打磨**：两个游戏的画面重做、在 Rhino 里对照截图调画面。
- **图标**：写图标提示词、接入 Codex 生成的图标（Codex 出图本身不计）。
- **文档、报告与计时**：README、方案文档、交付报告、截图、用时统计、图文手册。
- **审查与发布**：多代理审查与修复的主线时间、打包、上架文案、提交合并。

取整：每部分按最大余数法取整，保证每部分的格子数等于它的总分钟数（114、83、70、56、53、93、82、37）。
